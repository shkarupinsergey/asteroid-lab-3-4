## Описание проекта

Лабораторная работа 3.4 «Астероиды». Игрок управляет кораблём, уклоняется от астероидов и сбивает их ракетами. В начале партии три жизни, за попадание начисляется очко.

## Возможности игры

- Поворот, разгон и торможение корабля.
- Стрельба по астероидам и подсчёт очков. Ракета проходит через край поля и исчезает, когда истекает её время полёта.
- Потеря жизни при столкновении и новая партия после завершения игры.

## Требования к системе

Для запуска нужны Python 3.10 или новее, `tkinter`, Pillow 12.2.0 и графический рабочий стол. Проверено в Windows с Python 3.12. В Linux для системного Python может понадобиться пакет `python3-tk`.

## Установка и запуск

Откройте папку `asteroid` в VS Code. Для новой копии проекта создайте окружение на своём компьютере. В Windows можно выполнить эти команды в терминале из папки проекта:

```text
python -m venv --clear venv
venv\Scripts\python.exe -m pip install -r requirements.txt
venv\Scripts\python.exe main.py
```

На macOS или Linux используйте `python3` в первой строке и `venv/bin/python` в двух следующих. `--clear` пересоздаёт только папку окружения. В репозитории она сохранена как подтверждение работы с `venv`.

## Управление

- **Enter** или щелчок по названию игры запускает партию.
- **← / →** поворачивают корабль, **↑** включает двигатель.
- **Пробел** стреляет, **Esc** закрывает игру.

## Файлы проекта

В `main.py` находятся окно, игровой цикл и проверка столкновений. Настройки и пути к картинкам собраны в `config.py`. Для корабля, астероида и ракеты есть отдельные файлы `spaceship.py`, `asteroid.py` и `rocket.py`. Изображения лежат в `images`.

## Пример игры

Нажмите **Enter**, поверните корабль стрелкой и выстрелите пробелом в ближайший астероид. Если попали, счёт увеличится на одно очко. После завершения партии **Enter** запускает новую.
